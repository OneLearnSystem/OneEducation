ONEEDUCATION — CYAN INTERFACE UPDATE

This ZIP contains files only, with no folders inside it.

INSTALL ON YOUR EXISTING ONEEDUCATION SITE
1. Keep a backup of your current website files.
2. Extract this ZIP. Upload its files to the root of your existing OneEducation
   GitHub repository, replacing matching files and including the new files.
3. Keep your own config.js if you have changed its app links or school settings.
   The supplied config uses your nndjwqjyfgozltdoujiu Supabase project and
   existing publishable key. It contains no private service key.
4. Wait for your existing GitHub Pages deployment to finish, then refresh.
   Keep using your existing ?school=... address and login details.

SQL
No new SQL query is needed for this interface update if your integrated
OneEducation version already works. Do not reset or recreate your database.
The three older upgrade SQL files are included only for compatibility and
reference. They are not new migrations and do not need to be rerun for this UI.
This is an update for your existing installation, not a fresh platform installer.

WHAT CHANGED
- Cyan visual design throughout the existing feature pages and dialogs.
- New school overview for administrators and teaching overview for teachers.
- Grouped sidebar: Workspace, Students, Teaching, Pastoral, School, Administration.
- Search for students and classes, responsive navigation and visible save state.
- A new student homepage, profile sidebar, lessons, homework and notices.
- Existing timetable, detention, class, exam, points, import, role, On-Call,
  lockdown, funding, reports, and portal features remain connected.
- OneEasy staff connection and shared session refresh are retained.

USING THE DASHBOARDS
Teacher lessons match the signed-in email to the school's teacher record.
An unlinked teacher sees a clear message instead of another teacher's lessons.
Attendance today is present + late divided by all recorded marks for the selected
students today. It is not an official statutory attendance return.
Point totals use all recorded points for the selected students.
Students only see sections permitted by the existing school/year settings.
Click a sidebar group heading to expand it. On phones, use the menu button.
All existing server role checks, code logins, data and school isolation remain.

PREVIEW
Open index.html?demo=1 through your website to preview sample school data.
The demo is not a live school. Some advanced actions need a real approved account.
Do not double-click HTML files locally; browser modules require a web server.

This update has been checked locally against a temporary test database.
Nothing has been deployed to GitHub or changed in your live Supabase project.
